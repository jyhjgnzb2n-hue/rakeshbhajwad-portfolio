# Rakesh Bhajwad Portfolio

A premium personal portfolio website for Rakesh Bhajwad — aspiring web developer, AI developer, and cinematic horror content creator from India.

## Run & Operate

- `npm run dev` — start local dev server at http://localhost:5173
- `npm run build` — production build to `dist/`
- `npm run preview` — preview the production build locally

## Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS v4
- Framer Motion (animations)
- Wouter (routing)
- shadcn/ui components (Radix UI base)

## Where things live

- `src/pages/Home.tsx` — main portfolio page
- `src/components/sections/` — Hero, About, Skills, Projects, Interests, Contact
- `src/components/layout/` — Navbar, Footer
- `src/components/ui/` — shadcn/ui component library
- `src/index.css` — global styles and Tailwind theme (dark glassmorphism)
- `attached_assets/generated_images/hero-bg.jpg` — AI-generated hero background image
- `public/favicon.svg` — site favicon

## Vercel Deployment

- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`
- Framework: Vite

## User preferences

- Dark glassmorphism design — keep the premium dark aesthetic
- No fake/placeholder content — all content is real
- No emojis in the UI
